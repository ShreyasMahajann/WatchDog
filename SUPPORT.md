# Getting help

- **Questions and ideas:** ask on the [Ergane Foundation Discord](https://discord.gg/gZTJfUujX).
- **Bugs:** open an issue. Include your watchDog version (shown in Settings),
  the platform (Android version, Windows or Linux), and the steps to reproduce.
- **Documentation problems:** open an issue, or a pull request against `README.md`
  or `docs/`.
- **Security problems:** do not post them publicly; follow [SECURITY.md](SECURITY.md).

Before asking, check:

- [README.md](README.md), including its honest limits section;
- that the device is joined to the network you want to scan (Android can only
  scan the network it is connected to);
- that location permission is granted on Android 13 and later, which the
  nearby Wi-Fi list needs.

This project is maintained by volunteers, so answers can take a few days. There
is no paid support.
